**AI Coding Skills** is a community-maintained open-source initiative that provides skills, plugins, agents, prompts, instructions, and examples for AI coding tools.

## Mission

Make AI-assisted application development more consistent, reviewable, and production-minded—starting with Java frameworks and the AI coding platforms developers already use.

## What we maintain

- Platform-specific packaging for GitHub Copilot, Grok, and Claude Code
- Language-rooted framework docs, skills, examples, and guides
- Compatibility status that is easy to update
- This documentation site at [aicodingskills.dev](https://aicodingskills.dev)

## Organization

- Site: [https://aicodingskills.dev](https://aicodingskills.dev)
- GitHub: [https://github.com/AI-Coding-Skills](https://github.com/AI-Coding-Skills)
