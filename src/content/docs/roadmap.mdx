## Cross-cutting concerns

- Java testing
- Java modernization
- Security
- Observability

## Expansion

- Additional programming languages beyond Java
- Additional AI coding platforms beyond GitHub Copilot, Grok, and Claude Code
- Cross-language skill and example indexes once more than one language ships

## Sequencing principles

1. Ship one solid bootstrap path end-to-end before broadening widely.
2. Keep platform packaging separate from language documentation.
3. Update the [compatibility matrix](/languages/java/compatibility/) whenever status changes.
4. Prefer examples and tests that prove skill quality.

<Aside type="note">
Roadmap items are community goals, not delivery commitments. Propose changes via issues or pull requests in the relevant repository.
</Aside>
