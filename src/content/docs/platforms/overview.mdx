AI Coding Skills ships **platform-specific packaging** for the same language skills. Platform pages explain installation, plugin formats, repositories, and usage conventions. They do not duplicate full framework documentation.

## Why platforms are top-level

Each AI coding tool can support multiple languages over time. Keeping platform docs outside `/languages/` avoids nesting Copilot, Grok, or Claude Code under Java—and keeps the door open for additional languages without restructuring navigation.

## How platform docs relate to skills

1. Read the platform page for install and packaging rules.
2. Open the language skill page under [`/languages/java/skills/`](/languages/java/skills/) for purpose, prompts, expected structure, and limitations.
3. Use the [compatibility matrix](/languages/java/compatibility/) to see which platforms currently support each skill.

Framework deep-dives live under [`/languages/java/frameworks/`](/languages/java/frameworks/). Platform pages only link to those resources.
